Experimental · v0.8.6, pre-1.0

Tycho is a systems language without a garbage collector.

Memory is managed with implicit arenas: every scope owns one, and it empties when the scope ends. No manual free, no borrow checker. Built for parsers, compilers, and batch tools. Not for shared-mutable graphs.

01 — The idea

How it works.

Arenas per scopeEach scope gets an arena. Allocation bumps a pointer; exiting the scope frees everything at once.
No referencesb := a copies. Without aliasing, lifetimes are visible in the syntax.
Placed, not managedA value leaves a scope only down into a callee or up to a caller. The compiler places every allocation and every free.
02 — Speed

Why it is fast.

  • Returned values are built in the caller's arena — no copy on the way out (1.75× faster than copying).
  • acc = acc + x grows one buffer: O(n²) becomes O(n). 828 MB becomes 4 MB on the same input.
  • Copies happen only where a collector would do the same work. See the measurements ↗.
LISTING 01 — examples/count.tyone buffer · O(n)
fn main():
    total := ""
    for i := 1; i < 6; i += 1:
        total = total + str(i)
        if i < 5:
            total = total + ", "
    println("counted: " + total)   # counted: 1, 2, 3, 4, 5

Listing 01. Loop garbage that frees itself at scope exit.

LISTING 02 — examples/promote.tyreturn moves · zero copies
struct Person:
    name: string
    age: int

fn promote(p: Person) -> Person:
    q := p                # a full, independent copy
    q.age = p.age + 1
    return q             # moved into caller's arena, not copied

fn main():
    ada := Person("Ada", 36)
    older := promote(ada)
    println(str(ada.age) + " " + str(older.age))   # 36 37

Listing 02. Copied in, moved out; the original is untouched.

03 — Costs

What it costs.

Pointer-shaped dataCosts more than C: trie 1.55×, LRU 2.8× memory. The index-pool idiom brings graphs to 1.3×. Full accounting in the loss column ↗.
No interface valuesA mixed list of implementors can't exist; closed enums with match cover known sets, generics cover the static case. See Thinking in Tycho ↗.
Pre-1.0Breaking changes ship with a changelog entry and no deprecation window until 1.0 (policy ↗).
Scope exitA long-lived scope holds its transients until it returns.

05 — The language

What is included.

  • Value semantics, generics, sum types — Option / Result, match, $T monomorphized.
  • Methods, closures — UFCS, no classes; value capture.
  • Systems pieces — spawn, channels, parallel for; extern fn FFI; packages and a corelib.

Python-flavored syntax, Go/Odin-like semantics; the value core comes from Hylo ↗.

06 — Verification

How it is tested.

Corpus1,100+ fixtures, each built native and sanitized with byte-identical output, matched to committed goldens. 621 fixtures pin every refusal.
FuzzedRandom programs run native -O2 against ASan/UBSan; any disagreement is a defect. Malformed input must fail closed.
Authored evidenceMost programs above were written by the author. Outside programs are the 1.0 gate — see the roadmap ↗.
No cloud CImake ci runs everything on your machine. Caveats are written down in the performance notes ↗.

09 — Questions

Short answers.

No GC, no borrow checker — how is it safe?
There is no reference type, so a dangling pointer can't be written. Option replaces null, Result replaces exceptions; indexing is bounds-checked.
What does value semantics cost?
More memory for pointer-shaped data — see 03 above. Rule of thumb: if C would use pointers, budget extra or reach for the pool idiom.
Copying everything must be slow?
Returns, loop appends, and last uses don't copy — see 02 above.
Where's the package manager?
There isn't one, on purpose: vendor directories, import by path. No transitive graph you've never read. The packages page ↗ shows the shape.
