Experimental systems language · v0.8.6

No garbage collector. No manual free.

Tycho manages memory with implicit arenas: every scope owns one, and it empties when the scope ends. No garbage collector, no manual free, no borrow checker. It transpiles to C and builds with cc and make. New here? Start with the tutorial ↗.

01 — The idea

Memory comes from scope, not a runtime.

Scopes own arenasAllocation is a pointer bump. When the scope exits, the whole arena empties in one step — no per-object free, ever.
No referencesb := a copies. With nothing to alias, the compiler reads every value's lifetime straight from the syntax.
Placed, not managedA value leaves a scope only down into a callee or up to a caller. The compiler puts every allocation and every free where it belongs.

Arena lifetimes. Every bar ends at its scope's exit line. The highlighted value is returned, so it crosses that line and lives on in its caller.
02 — Why it stays fast

Value semantics, minus the copies you'd expect.

Returns moveA value you build and return is allocated straight into the caller's arena. return moves it — 1.75× faster than copying it out.
Loops growacc = acc + x grows one buffer in place: the textbook O(n²) string build becomes O(n) — 828 MB down to 4 MB at the same input.
Dead values moveA copy happens only where a GC would work too. The numbers ↗ are measured, not asserted.
LISTING 01 — examples/count.tyone buffer · O(n)
fn main():
    total := ""
    for i := 1; i < 6; i += 1:
        total = total + str(i)
        if i < 5:
            total = total + ", "
    println("counted: " + total)   # counted: 1, 2, 3, 4, 5

Listing 01. The string built inside the loop lives in main's arena — the compiler frees it for you on return.

LISTING 02 — examples/promote.tyreturn moves · zero copies
struct Person:
    name: string
    age: int

fn promote(p: Person) -> Person:
    q := p                # a full, independent copy
    q.age = p.age + 1
    return q             # moved into caller's arena, not copied

fn main():
    ada := Person("Ada", 36)
    older := promote(ada)
    println(str(ada.age) + " " + str(older.age))   # 36 37

Listing 02. return moves the value into the caller's arena; the copy q := p stays independent.

03 — The costs

Stated before you commit.

No referencesShared-mutable graphs and observers can't be written the pointer way. Pools + indices are the idiom — the cache-friendly one — and the loss column ↗ names every price: trie ~1.55× C, LRU ~2.8×, graph idiom ~1.3×.
No interface valuesA heterogeneous list of implementors can't exist here. Closed enums + match cover the known set, generics the static half — the replacements are in Thinking in Tycho ↗.
Pre-1.0The surface can still break with a changelog entry and no deprecation window. The policy is in SUPPORT ↗. Arenas free at scope exit, not incrementally.

04 — FAQ

Asked every time.

No GC, no borrow checker — how is it safe?
There is no reference type, so a dangling pointer can't be written. Memory frees per scope, Option removes null, Result removes exceptions, indexing is bounds-checked.
What does value semantics cost?
Pointer-shaped data stored by value: trie ~1.55× C, LRU ~2.8×, the pool idiom ~1.3×. Arenas free at scope exit, not incrementally. The loss column ↗ names every price.
Copying everything must be slow?
"Copied" is the model, not the code: returns move, acc += x grows in place, dead values move. A copy happens only where a GC would work too. The numbers ↗ are measured.
Where's the package manager?
There isn't one, on purpose: vendor directories, import by path. No transitive graph you've never read. The packages page ↗ shows the shape.

07 — How it's checked

Experimental in scope. Not in rigor.

Corpus1,100+ fixtures built twice — native and sanitized — byte-identical output required, matched against committed goldens. 621 refusals pin every rejection.
FuzzedRandom programs run native -O2 against ASan/UBSan; disagreement is the oracle. Malformed input must fail closed — never crash.
Gated, locallymake ci runs the whole suite on your machine. No cloud CI to take on faith — and every gate proves it can fail.
