Tycho is a systems
programming language.

Write native programs with automatic memory management—without a garbage collector. Tycho is designed for parsers, interpreters, and other tools that create lots of temporary data.

Try Tycho Read tutorial
A small Tycho programTycho
fn evens(limit: int) -> [int]:
    xs := []int
    for i := 0; i < limit; i += 1:
        if i % 2 == 0:
            push(xs, i)
    return xs

fn main():
    xs := evens(10)
    println(str(len(xs)))   # 5

Collect the even numbers below 10 and print their count. The array can grow and be returned without manual allocation or cleanup.

The approach

Less memory bookkeeping.

Tycho uses the structure of your program to decide how long data lives. You work with strings, arrays, and structs; the compiler handles their storage. There are no manual frees or borrow-checker annotations.

Automatic cleanupMemory is grouped into arenas: blocks of memory owned by a scope. When that scope finishes, its arena is released. Returned values remain available to the caller.
Independent valuesAssigning an array or struct creates an independent value. Changing the copy does not change the original. This is value semantics, and it replaces shared ownership with a different way to organize data.
Native executablesThe compiler translates Tycho into C, then uses GCC or Clang to build an executable. You can also call existing C libraries through an explicit foreign-function interface.

For a worked explanation, read from manual allocation to arenas. The tradeoffs below explain where this model is a poor fit.

Writing Tycho

Familiar building blocks.

Indentation-based syntax keeps the small examples readable. Beyond memory management, Tycho includes the tools for writing larger programs:

  • Model your data. Strings, arrays, maps, structs, and enums, with pattern matching for handling different cases. Option represents a missing value; Result represents an operation that can fail.
  • Reuse your code. Generics and closures, plus corelib packages for text, files, networking, and other common tasks. Packages are imported by path; there is no package manager.
  • Coordinate work. Tasks and channels, with parallel loops for work that can be split across multiple workers.

The tutorial introduces these through small programs. The language and corelib reference covers the details.

Before you choose it

Know the tradeoffs.

Tycho’s memory model is a deliberate trade: less ownership bookkeeping in exchange for fewer ways to share data. It is worth exploring for data-processing tools and native-programming experiments, but it is not a drop-in replacement for C, Rust, or Go.

Different data structuresThere is no reference type for sharing mutable objects. Graphs and linked structures use arrays of nodes connected by integer indices instead of pointers. Thinking in Tycho shows the alternatives.
Memory tradeoffsArenas reclaim memory at scope exit, not as soon as each value stops being useful. Long-lived scopes can retain temporary data, and some data structures use more memory than their C counterparts. Read the measured limitations.
No interface valuesYou cannot mix unrelated types behind one runtime interface. Use generics when the types are known in advance, or enums when the possible variants are fixed.
An early-stage projectExpect language and corelib API changes before 1.0. The project is still seeking real programs from outside developers and an external security audit. Read the version policy and roadmap.

Do not use Tycho for security-critical work. Calls into C are an unsafe boundary; the security policy explains the limits.

Get started

Try a small program.

To build from source, you need Git, make, and a C11 compiler: GCC or Clang 15 or newer. Check the platform setup for your system.

Build and run the greeting exampleTerminal
$ git clone https://github.com/StefanVonRanda/tycho
$ cd tycho
$ make
$ ./tychoc examples/hello.ty && ./examples/hello
built examples/hello
what is your name: Ada
hello Ada

The example asks for a name. Type Ada to get the greeting shown here.

Prefer a prebuilt compiler? See the v0.8.6 release downloads for available builds and checksums. You still need a C compiler to build Tycho programs.
