◇ 001 — SYSTEM TYCHO An experimental systems language · transpiles to C

Automatic memory management.
No garbage collector, no manual free.

A research project testing one idea: implicit hierarchical arenas under value semantics. Every scope owns a memory arena, freed on exit. There is no reference type, so the compiler can place every allocation and free from your code's structure alone.

01 The idea

Memory comes from scope, not a runtime.

A /

Every scope owns an arena

Allocation is a pointer bump. When the scope exits, the whole arena is freed in one step.

B /

No reference type

b := a copies. The compiler sees every value's lifetime from the syntax alone.

C /

Compiler-placed memory

Every allocation and free is inserted for you — no GC, no manual free, nothing to annotate.

A string built across a loop lives in main's arena, freed for you on return

examples/count.tyone buffer · O(n)
fn main():
    total := ""
    for i in range(1, 6):
        total = total + str(i)
        if i < 5:
            total = total + ", "
    println("counted: " + total)   # counted: 1, 2, 3, 4, 5

02 Why it stays fast

Value semantics, without the copies you'd expect.

  • A value can leave a scope only two ways, both visible in the source: down into a callee, or up to the caller.
  • A value you build and return is allocated straight into the caller's arena — return moves it, it doesn't copy.
  • acc = acc + x in a loop grows one buffer in place: the textbook O(n²) string build becomes O(n).

Where the model helps and where it costs are both measured — as machine-specific ratios, with the workloads that produce them — in the performance notes ↗. Pointer-shaped data like graphs and trees is where value semantics is least free, and the docs are honest about that.

Both moves are sound because a value is never aliased — a copy is always independent

examples/promote.tyreturn moves · zero copies
struct Person:
    name: string
    age: int

fn promote(p: Person) -> Person:
    q := p                # a full, independent copy
    q.age = p.age + 1
    return q             # moved into caller's arena, not copied

fn main():
    ada := Person("Ada", 36)
    older := promote(ada)
    println(str(ada.age) + " " + str(older.age))   # 36 37

04 How it's checked

An experiment, but a heavily-checked one.

2compilers — C reference + Tycho self-host
byte-for-byteself-emission fixed point
ASan+UBSandifferential fuzz both compilers
make cithe whole gate, on your machine
self-hostTwo compilers: a reference written in C, and a frozen compiler written in Tycho that compiles itself, running on the same implicit arenas it emits. make selfhost-check re-proves the fixed point at every commit — the Tycho-built compiler reproduces its own emitted C byte-for-byte.
fuzzA differential fuzzer runs both compilers on random programs under ASan/UBSan; every example is built twice — native and sanitized — and checked against a committed golden output.
localThere's no cloud CI to take on faith. make ci runs the whole gate on your own machine.

It's experimental in scope, not in rigor — the honest caveats live in the performance notes ↗.
