# Release 0.9

This release makes Tycho easier to try and nicer to use. The highlights:

- a dependency-free C transpiler: install it and build
- a corelib that keeps growing with every release
- C FFI, so you can call the libraries you already rely on

## Try it

Grab the release, build the examples, and tell us what breaks. Your bug
reports shape what lands next.
