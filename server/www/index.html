tycho-httpd

A static web server written in Tycho.

What this page proves

Everything you are looking at came off a socket handled by a Tycho program: this HTML, the stylesheet, the script below, the PNG in the header, the favicon in your tab, and the font these words are set in. Nothing is proxied and nothing is precompiled into the binary — each response is a file read off disk at request time, with a content type picked from its extension.

  • bytes bodies, so binary assets are served byte-for-byte
  • HTTP/1.1 keep-alive, so this page costs one TCP connection, not seven
  • a fixed pool of worker tasks, each running its own accept loop
  • path traversal refused before the filesystem is touched

Try it

Links that exercise the interesting paths:

  • /about/ — a directory index
  • /about — redirects to /about/
  • /img/dot.png — a 16×16 PNG
  • /fonts/quicksand-regular.ttf — 95 KB of font
  • /robots.txt — text/plain
  • /data.json — application/json
  • /nope — a 404
  • /../etc/passwd — refused (your browser will normalise it away; use curl --path-as-is)

Live check
