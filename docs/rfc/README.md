# RFCs

Proposals, resolved and open. Maintainer material — a proposal describes what
the language might do, which is not the same as what it does. For current
behaviour, read [`../reference/`](../reference/).

- [`parallel-for-width.md`](parallel-for-width.md) — **built.** The
  `parallel(W) for` width slot; what shipped is recorded at the end of the file.
- [`value-lifetime-regions.md`](value-lifetime-regions.md) — value lifetime
  regions.
- [`or-return-mapping.md`](or-return-mapping.md) — **proposal, measured.**
  `or_return` with an error-mapping expression; 42 sites measured, spelling
  not chosen.
- [`limited-references-spike.md`](limited-references-spike.md) — the spike behind
  subscripts, the one limited-reference construct that fits the arena model.
- [`ffi-threading-design-review.md`](ffi-threading-design-review.md) — FFI and
  threading, reviewed together.
