# 1.0 readiness

Snapshot: **2026-11-12**. Internal engineering is complete for the 1.0 scope in
[ROADMAP](../../ROADMAP.md#what-10-requires). 1.0 is not declared because both
remaining gates need a person who is not the author.

The tree has **one maintained compiler**. `compiler/` is the self-hosted
implementation; `bootstrap/tycho_compiler.c` is the generated cold-start
artifact; the historical `src/tychoc.c` is deleted and its citations resolve
through git history.

| Row | Tycho | C |
|---|---:|---:|
| `dispatch` default | 13 ms | 13 ms |
| `dispatch` expert | 12 ms GCC / 26 ms clang | 13 / 30 |
| `json_tree` time | 51 ms | 49 ms |
| `json_tree` RSS | 81.7 MB | 103.6 MB |

| `trie` time | 89 ms / 90 ms clang | 79 / 74 |

The remaining losses are structural: the generic int map's duplicate
key/value/index arrays (`lru` RSS) and the last few percent in trie and
dijkstra. The expert `binary/arena` row now uses a 16-byte null-leaf node and is
at clang parity; GCC spends the difference in recursive arena allocation.

## What is still missing

### 1. A real program written by someone who is not the author

This is the blocking 1.0 gate. Four outside probes exist — `tools/tycho-diff`,
`tools/tycho-hash`, `tools/tycho-fold`, and the 2026-08-19 FFI probe — each with
its friction recorded. They do not cover generics, `subscript`, `bounded[N]`,
`select`, and error paths. The procedure is
[probe-procedure.md](probe-procedure.md).

### 2. An external security review

No third-party audit has been performed. The reviewer packet is
[audit-brief.md](audit-brief.md). Three internal passes found 5, 9 and 10
issues with zero overlap, which is why this remains a requirement rather than a
conclusion.

### 3. Owner actions outside the code

- Keep the macOS arm64 archive in the release set. 0.9.2 has a native Apple
  Silicon build; 0.9.1 shipped Linux and Windows only.
- Decide whether the ergonomics backlog is 1.0 work or post-1.0 work.

`make status` is the live health check. `make release-check` rebuilds and
compares the archives. The commands in this document are the reproducible
evidence for the table above.
