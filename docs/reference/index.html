    Tycho language reference

    How each part of Tycho behaves, with runnable examples. New here? Start with the tutorial. Curious why the language works this way? Read From malloc to arenas, then the thesis for the full argument.

    Every example compiles and prints the output shown.

    Conventions

    • One spelling per idea. Where two spellings could do the same job, Tycho keeps one. Each page names it.
    • Values copy. b := a gives b its own independent copy. Two variables never share mutable storage. Each page shows what that means for its own types.
    • Examples run. Every sample compiles under tychoc. Output shown in a comment is the actual output.

    Before the first real program, read Quiet results — the seven places the language answers instead of refusing.
