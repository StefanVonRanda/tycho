    corelib — Tycho's core library

    Memory: Every corelib function puts its results in the caller's memory and returns independent values, never aliasing the inputs. The one exception is a C-owned opaque handle (ptr) from the C-backed packages below, which is not caller-managed: release it with that package's own free function.

    corelib is Tycho's core library: a set of packages under corelib/, imported with the core: collection root. The modules below are usable today.

    package main

import "core:math"

fn main():
    println(f"gcd={math.gcd(12, 18)}")

    Quick start

    1. import "core:<pkg>" in your source. The name <pkg> is bound to the package. The transpiler finds corelib/ next to its own binary by default, so no setup is needed in this repo. Set TYCHO_CORELIB to a corelib directory to override.
    2. Call its functions either free-standing (math.gcd(12, 18)) or method-style (x.abs() — any function can be called with its first argument as the receiver, see Methods).

    Resolution

    import "core:<pkg>" resolves to <corelib>/<pkg> and binds the name <pkg>, where <corelib> is TYCHO_CORELIB if set, otherwise corelib/ next to the transpiler binary. Non-core: imports stay relative to the importing package, unchanged. tychoc resolves core: natively, with no bundling step required.

    How corelib is shaped

    corelib is generic free functions over a type parameter $T, with where constraints (comparable(T), numeric(T), has_str(T)) picking which element types each function accepts. Array and iterator utilities are single generic packages over any element type [$T] (core:arrays, core:iter) rather than one package per element type. The functions are also callable method-style through method-style call, so index_of(xs, v) and xs.index_of(v) are the same call.

    Higher-order helpers (map / filter / reduce that take a function) live in core:iter and its siblings, and take a first-class fn/closure argument. Lambdas in Tycho are expression-bodied; pass a named function where you need a multi-line body.

    Packages

    • math — min/max/clamp(x, lo, hi) are generic over any comparable type (int/float/string/char) and lane-wise at a vector[N]T; sign(x) over any numeric type (returns an int −1/0/1); abs, gcd, ipow(base, exp) (exp ≥ 0) are integer- specific. (sqrt/pow/floor/fabs are float builtins.)
    • fmath — float-only helpers (scalar min/max/clamp/sign live in math): pi, e, round (half away from zero), trunc, lerp(a, b, t), approx_eq(a, b, eps), degrees/radians, and a libm bridge: sin, cos, tan, asin, acos, atan, atan2(y, x), sinh, cosh, tanh, exp, log, log2, log10, hypot(a, b).
    • gfx — an SDL3-backed window, 2D renderer and stream-audio shim (deps: sdl3). Handles Window, Audio and TexSet; types Event, FRect, IRect, FVec, View, AssetSpec, Controls, Clock, Sprite, Anim, Mixer. begin, draw_fb, draw_lines, present, poll_event, set_title, window_width, window_height, fit_view, view_rect, view_fvec, default_controls, action, clock_start, clock_advance, clock_tick, tex_create, tex_draw, draw_sprite, anim_frame, draw_anim, audio_queue, mixer, add, finish, play_mix, repeat, play_loop, load_manifest, load_texture, draw_atlas_text, draw_text_view, draw_text_centered, draw_text_centered_view, text_width, fill_rect, rgb, make_beep, play_beep, save_bmp. draw_fb accepts a framebuffer whose width/height may be smaller than the window; the shim uploads it at source resolution and scales it into dst (the software-3D example renders at 480×270 and scales to the window). Event kind values are: 0 none, 1 quit, 2 key down, 3 mouse move, 4 mouse button, 5 resize, 6 key up. A TexSet owns its textures and is scope-freed; SDL3 must be installed and selected with --pkg sdl3. The boundary rule is recorded in design-gfx: values and affine handles only, no public ptr, callbacks or unions.
    • gfx3d — a pure software 3D camera, mesh and flat-shaded triangle rasterizer. Types Vec3, Camera, Target, SVert, Tri, Mesh, Place; functions look_at, project, draw_tri, draw_quad, draw_box, clear, mesh, add_tri, add_quad, add_box, draw_mesh. There is no SDL, handle or pointer in this package: the caller owns the framebuffer, depth buffer, target dimensions and ARGB colours. draw_tri clips against the near plane and interpolates inverse depth with the corrected barycentric weights. Mesh holds local-space triangles; Place applies a caller-built right/up/forward basis, origin and uniform scale without copying the mesh. examples/gfx/3d, examples/gfx/orbit and examples/gfx/rotor are its callers.
    • gfxgpu — the first SDL_GPU backend. It owns a GPU device, swapchain, depth texture and graphics pipeline for a gfx.Window; the Tycho side is the affine Gpu handle plus an external frame call. Shaders are committed SPIR-V and are translated to the native backend by SDL_shadercross. Build the pinned runtime with scripts/build-shadercross.sh; this package is not available on a host without SDL_shadercross. The public function is gfxgpu_close; the handle-returning open and frame entry points are declared by the caller, the same affine-opener pattern as core:gfx. The probe draws a depth-tested triangle; Vector Vault and Rotor Run render world-space scenes with camera MVP uniforms and GPU HUD overlays directly to the SDL_GPU swapchain. The offscreen readback variant remains available as a fallback/probe path.
    • char — byte/char classification & conversion over int byte values (what s[i]/chr use): is_digit, is_alpha, is_alnum, is_upper, is_lower, is_space, is_hex, to_upper/to_lower (one byte), digit_val (−1 if not a digit), hex_val (0..15 or −1).
    • fmt — width-aware formatting over core:strings: format_int(n, width, base, upper, pad), format_float(v, digits, width, pad), pad_left and pad_right. Bases are 2..36; floats keep trailing zeros.
    • strings — to_upper, to_lower, starts_with, ends_with, contains, repeat(s, n), trim (ASCII whitespace), parse_int, parse_u64, parse_int_prefix, is_space, fields (splits on runs of ASCII whitespace, dropping empty edge fields), lines (splits on \n, drops one trailing \r per line, trailing newline adds no empty line), replace (non-overlapping, left to right; empty old returns the input unchanged), count(s, sub), strip_prefix/strip_suffix, pad_left/pad_right(s, width, pad) (pad is one byte), reverse, capitalize, split_once(s, sep) -> (before, after) ((s, "") if absent). (split/find/substr/len/chr are builtins.) The integer parser is fail-closed by default: parse_int(s) -> Result(int, IntErr), parse_u64(s) -> Result(u64, IntErr) and parse_float(s) -> Result(float, FloatErr) refuse an empty string, a sign where unsigned, trailing garbage and out-of-range input (u64 above 18446744073709551615). parse_int_prefix(s) -> int is the explicit fail-open scanner ("3x" is 3), for grammars that consume a numeric prefix; do not use it on a file, a socket or a user. slice_str(s, start, stop) -> Result(string, SliceErr) and slice_bytes(b, start, stop) — a plain slice clamps rather than bounds-checking (b[1:99] on three bytes gives two and no trap), so these are the forms that refuse an out-of-range window instead of narrowing it. format_g17(v) renders a float at the 17 significant digits that round-trip; format_float(v, digits) is fixed notation with 0..17 digits after the point and keeps trailing zeros. format_int_base(n, base, upper) and parse_int_base(s, base) cover bases 2..36 (parse_int_base is fail-closed like the decimal parser; format_int_base handles the minimum int).
    • scanner — a positioned byte scanner for hand-written parsers. new(s), pos/line/col (1-based line/column), peek/peek_at, next, accept(lit) (consume only on a match), expect, skip_ws, read_while(pred), read_ident, read_int (optional sign; advances only on success), read_line (LF/CRLF) and eof.
    • buffer — a mutable binary buffer: new, size, write (string), write_byte, write_bytes, reserve_cap, as_bytes, as_string and clear. It stores bytes in an [int] and converts once when read.
    • glob — shell-style wildcard matching. matches(pattern, s) treats * and ? as matching any byte including /; matches_path stops them at / but lets ** cross it. Both support [abc], [a-z] and [!…]/[^…] classes and a backslash escape.
    • table — ASCII tables. make(headers, rows) then render(t) -> string; columns are padded to the widest cell, missing cells render empty, and widths are byte lengths.
    • bufio — an in-memory reader/writer for parsers and small protocols. Reader tracks a byte position: new_reader(s), peek, peek_at(r, n), read_byte, unread, skip_ws, read_until(r, sep), read_line (LF/CRLF, Some("") for an empty line), read_int (optional sign plus at least one digit; advances only on success), rest, remaining, pos, eof. Writer accumulates text: new_writer, write, write_byte, write_line, text, reset. This is a string buffer, not an fd-buffering layer.
    • filepath — Windows-style lexical paths, independent of the host. Both / and \ are separators; clean preserves a drive (C:) or UNC (\\server\share) volume and resolves ./.. without climbing above the root. is_abs, volume, split_volume, join, base, dir, ext and stem are the corresponding operations. Use core:path for POSIX semantics.
    • path — POSIX path utilities (separator /). The pure functions below are string math only (no filesystem access, every function returns a fresh value): base (final element, trailing slashes ignored; ""→., "/"→/), dir (all but the final element), ext (extension incl. the dot, "" if none; a leading dot is a dotfile, not an ext), stem (base minus ext), join(a, b) (exactly one separator, empty operands drop out), is_abs, split_path(p) -> (dir, base) (the inverse of join), and clean (lexical normalize: collapse //, drop ., resolve .. but never above the root or past a leading ..). relative(base, target) is the lexical inverse of joining: both paths are cleaned, common leading segments are dropped, and each remaining base segment becomes .. (/a/b to /a/c is ../c). It does not resolve symlinks or require either path to exist, and a mixed absolute/relative pair returns the cleaned target unchanged. last_slash(s) is the shared scan helper (index of the last /, or -1). quote(p) is POSIX shell-safe single quoting for display ('a b', and an embedded quote as '\''), so a text report can print an arbitrary path as one unambiguous word. safe_join(base, rel) is the lexical containment prefilter: the cleaned join when an untrusted rel stays under base, "" when it is absolute, escapes via .., or carries a backslash or an X: drive prefix. safe_join_checked(base, rel) -> Result(string, PathErr) is the same rule with the cause: Ok(path) or Err(BadPath).

    The filesystem fence. A lexical check cannot see a symlink, so four functions make a real syscall, and all fail closed — "" is a refusal and callers must treat it as one before using the path.

    • real_checked(p) — the checked sibling: Ok(resolved) or Err(NotFound / Denied / TooLong / BadPath / Failed). Use this when the caller has to report *why* a path could not be resolved.
    • real(p) — the absolute path with every symlink and .. resolved, or "" if the path does not exist, cannot be read, contains a NUL, or does not fit.
    • under(root, p) — true when p is root or lies underneath it. The comparison only, not the resolution: both arguments must already be resolved.
    • resolve_under(base, rel) — the one to reach for first when a path is built from untrusted input; safe_join is the cheap prefilter inside it. It returns the path to use, or "" when rel is refused — refused lexically, or because the resolved answer lands outside base, or because base itself does not resolve. A path that does not exist is not a refusal: the longest existing ancestor is resolved and checked instead, so the caller reports its own "not found" rather than a spurious "forbidden". A dangling symlink is refused. resolve_under_checked keeps the same answers with the reason: Ok(path) for a resolved path *or a missing leaf*, Err(BadPath) for a refusal, and the base's own PathErr (NotFound, Denied, …) when the root itself cannot be resolved.

    One caution: a check followed by a separate open can race if an attacker can write inside the root. resolve_under narrows that window to an attacker with write access inside the root; a fully race-free form would need the open done inside the check.

    • complex — a float Complex{re, im}: make, add, sub, neg, scale, mul, div, conj, abs2, abs, arg, exp and log (trig/exp/hypot through core:fmath).
    • fixed — signed Q16.16 fixed point (Fixed): from_int, from_float, as_float, to_int_trunc, zero, one, add, sub, neg, abs, mul, div, floor_fixed, frac, round, sign.
    • noise — deterministic value noise: value1(x, seed), value2(x, y, seed), value3(x, y, z, seed) in [-1, 1], gradient perlin2(x, y, seed), and fbm2/fbm3 with octaves, lacunarity, gain and seed.
    • linalg — float vectors and 4×4 matrices. Vec2/Vec3/Vec4 with vec2/vec3/vec4, add2/add3/add4, sub2/sub3/sub4, scale2/scale3/scale4, dot2/dot3/dot4, length2/length3/length4, normalize2/normalize3/normalize4, lerp2/lerp3/lerp4, cross3. Mat4 is column-major (m[column * 4 + row]): mat4_identity, mat4_mul, mat4_transform, mat4_translate, mat4_scale, mat4_rotate_x, mat4_rotate_y, mat4_rotate_z, mat4_transpose, mat4_perspective (OpenGL depth range) and mat4_look_at.
    • bits — fixed-width bit operations: rotl32/rotr32/rotl64/rotr64 (negative counts rotate the other way), popcount32/popcount64, clz32/clz64 and ctz32/ctz64 (return 32/64 for zero), bswap16/bswap32/bswap64, and reverse32/reverse64.
    • ease — standard easing curves over t in [0, 1]: linear, quad, cubic and quart in/out/in-out (in_quad, out_quad, in_out_quad, in_cubic, out_cubic, in_out_cubic, in_quart, out_quart, in_out_quart), in_sine/out_sine/in_out_sine, in_expo/out_expo/in_out_expo, in_circ/out_circ/in_out_circ, in_back/out_back/in_out_back, in_elastic/out_elastic/in_out_elastic, and in_bounce/out_bounce/in_out_bounce.
    • arrays — generic utilities over any element type [T]: contains, index_of (−1 if absent), count, reverse, take(xs, n), drop(xs, n), concat(a, b), fill(n, v), dedup (consecutive — sort first for a full dedup); sort (ascending), is_sorted, min, max (where comparable — int/char/float/string); sum, product (where numeric — int/float); join(xs, sep) (where the element converts to a string). All return a new array — value semantics, the input is never mutated. min/max/sum/ product seed from xs[0], so they need a non-empty array. (push/pop/len/range are builtins; higher-order map/filter/reduce live in iter.)
    • iter — generic higher-order helpers over any [T], each taking a fn/closure: map (two type variables — map(xs: [$T], f: fn($T) -> $U) -> [$U], the only one that may change element type, so iter.map(nums, to_str) is a [string]), filter, reduce, count, any. Fallible stages get two siblings whose callback returns a Result: try_map(xs, f: fn($T) -> Result($U, $E)) -> Result([$U], $E) and try_filter(xs, keep: fn($T) -> Result(bool, $E)) -> Result([$T], $E). Both stop at the first Err and return it unchanged. reduce/count/any have no fallible form — write the for loop with or_return if you need one.
    • sort — argsort(keys) / argsort_desc(keys): return the index permutation that orders the keys — generic over any comparable key type (int/float/string/char). The way to order data by a derived value: keep it in parallel arrays, argsort one, and walk every array through the permutation. All stable. Plus by_key(xs, key): sort an array by a derived int key (a fn/closure) — deprecated since 0.5.0, removed in 1.0: it is sort_by(xs, fn(a, b) -> int: key(a) - key(b)). When the order needs more than one key, mixed directions, or a type with no comparable instance, sort_by(xs, cmp) takes a three-way compare fn($T, $T) -> int — bottom-up merge, stable, so equal elements keep their input order under a descending compare too. asc(a, b) and desc(a, b) are the two ready-made comparators for that parameter, so the common orderings need no lambda: sort_by(xs, sort.asc).
    • edit — byte-oriented edit distance: levenshtein(a, b) (two-row, O(min) memory), damerau(a, b) (unrestricted adjacent transposition) and similarity(a, b) -> float (1 - distance / max(len); both empty is 1.0).
    • diff — line diff: lines(a, b) -> [Op] where Op is Same, Delete or Insert. Common prefixes/suffixes are trimmed first; the middle uses a bounded LCS table, falling back to delete-all/insert-all above two million cells. unified(a, b, context) -> string emits --- a / +++ b hunks with explicit ranges, or "" when the inputs are equal.
    • pool — a generational node pool for pointer-shaped data (graphs, trees, doubly-linked structures). Hold every node in one array and link by integer index; pool packages that idiom. Generic over the element type Pool($T): add(&p, v) -> Handle, get(p, h), set(&p, h, v), remove(&p, h), alive(p, h), count(p), and live(p) -> [Handle] (all live handles in slot order — the way to walk a pool). A Handle carries a slot index plus a generation; every access checks the generation, so a handle to a freed-and- reused slot is caught at runtime instead of silently reading the new occupant. Create one with p := pool.Pool([]pool.Slot(int), []int). It removes the hand-rolled bookkeeping, not the cost: pointer-shaped storage costs more in this model (see value-semantics limits).
    • container — value-semantics data structures that arrays and maps do not cover. Deque is a two-stack, amortized-O(1) double-ended queue: make_deque$(T)(), deque_push_front/deque_push_back, deque_pop_front/deque_pop_back, deque_peek_front/deque_peek_back, deque_get, deque_len, deque_empty, deque_clear. Queue wraps it as a FIFO: make_queue$(T)(), queue_push/queue_pop/queue_peek, queue_len, queue_empty, queue_clear. PriorityQueue is a binary heap ordered by a caller-supplied less(a, b) where true means a is served first: make_heap(less), heap_push, heap_pop, heap_peek, heap_from(xs, less) for O(n) heapify, heap_len, heap_empty, heap_clear; ties are not stable. BitArray is a bounds-checked packed bit set over [u64]: make_bits(nbits), bits_set, bits_clear, bits_toggle, bits_get, bits_count, bits_any, bits_none, bits_resize, bits_len. Lru is a capacity-bounded cache: make_lru$(K, V)(cap), lru_put, lru_get (promotes the hit), lru_peek (does not), lru_remove, lru_contains, lru_keys (most recently used first), lru_len, lru_empty, lru_cap, lru_clear. Treap is an ordered map: treap_make(less, sample) (the sample only fixes the value type), treap_put, treap_get, treap_contains, treap_remove, treap_len, treap_empty, treap_keys (in-order), treap_first_key, treap_last_key and treap_clear. topo_sort(n, edges) -> Result([int], TopoErr) is Kahn's deterministic topological sort (Cycle on a cycle or an out-of-range edge). Avl is a balanced ordered map: make_avl(less, sample) (the sample only fixes the value type), avl_put, avl_get, avl_contains, avl_remove, avl_len, avl_empty, avl_keys (in-order), avl_first_key, avl_last_key and avl_clear. RbTree is a red-black ordered map with the same surface: make_rbtree(less, sample), rb_put, rb_get, rb_contains, rb_remove, rb_len, rb_empty, rb_keys (in-order), rb_first_key, rb_last_key and rb_clear. HandleMap is a generation-checked sparse map: make_handle_map(sample), handle_map_add (returns an int handle), handle_map_get, handle_map_valid, handle_map_remove, handle_map_len and handle_map_clear; removing a handle invalidates it even when its slot is reused. SmallArray is an inline fixed-capacity array of 16: make_small_array(sample), small_array_len, small_array_cap, small_array_space, small_array_push (false when full), small_array_pop, small_array_get, small_array_set and small_array_clear. Xar is a freelist-backed sparse array: make_xar(sample), xar_add (returns an index), xar_get, xar_set, xar_remove, xar_len and xar_clear. Every container is a deep value: copying one gives an independent container. core:pool remains the arena-friendly node pool; HandleMap is the integer-handle map.
    • sync — pthreads/Win32 primitives and C11 atomics, for state shared by spawn/parallel for tasks. Every object is a C-owned ptr handle with an explicit free; free only after every task that uses it has been joined. All atomic operations are sequentially consistent. atomic_int_new(v), atomic_int_free, atomic_int_load, atomic_int_store, atomic_int_add and atomic_int_sub (both return the new value), atomic_int_swap (returns the old value), atomic_int_cas(p, expected, desired) -> bool, and atomic_int_compare_swap (returns the value observed at the exchange, whether it won or lost). atomic_bool_new, atomic_bool_free, atomic_bool_load, atomic_bool_store, atomic_bool_swap, atomic_bool_cas mirror them. mutex_new/mutex_free, mutex_lock, mutex_try_lock, mutex_unlock are non-recursive; rwlock_new/rwlock_free, rwlock_read_lock/rwlock_try_read_lock/rwlock_read_unlock, rwlock_write_lock/rwlock_try_write_lock/rwlock_write_unlock allow many readers or one writer. waitgroup_new/waitgroup_free, waitgroup_add(w, n), waitgroup_done, waitgroup_wait join a dynamic task count. once_new, once_free, once_done, once_do(o, f) run f exactly once: the first caller runs it, later callers block until it finishes. f must not re-enter the same once object. cond_new/cond_free with cond_wait(c, m) (caller holds m), cond_timed_wait(c, m, ms) -> bool, cond_signal and cond_broadcast; semaphore_new(n)/semaphore_free, semaphore_wait, semaphore_try_wait, semaphore_post, semaphore_count are a counting semaphore; atomic_ptr_new(p)/atomic_ptr_free with atomic_ptr_load, atomic_ptr_store, atomic_ptr_swap and atomic_ptr_cas give a sequentially-consistent atomic pointer cell (null is a legal value). barrier_new(n)/barrier_free/barrier_wait release n waiters together (one gets 1, the rest 0), and recursive_mutex_new, recursive_mutex_free, recursive_mutex_lock, recursive_mutex_try_lock and recursive_mutex_unlock allow the owning thread to re-enter. Channels are language builtins (channel, send, recv, close), not part of this package.
    • intern — hash-consing / interning: canonical storage of values keyed by a hashable key. Generic Interner($K, $V): intern(&i, k, v) -> Handle returns the canonical handle for key k — the first sight stores v and mints the handle, every later sight of the same key returns the same handle and ignores its v — plus get(i, h) and count(i). Two handles are equal iff their keys were equal at first sight, so interning gives a cheap identity test and one canonical copy of each logical object. Handles are stable for the interner's lifetime; values are never removed — it is a *canonicalization* table, not a cache, so an unbounded working set grows by design (use a plain [K: V] map for a bounded cache). Keys are any map-key type — string, [int], a struct, a tuple. Create one with i := intern.Interner([]int, []string: int).
    • rand — deterministic xorshift32 (not cryptographic). No globals in Tycho, so the state is an explicit int threaded via inout (the & marks the inout call site, Basics). There is no rand.State type — a function of your own that draws numbers declares the parameter as a plain int, fn pick(st: inout int) -> int. Calls: st := rand.seed(42), rand.next(&st) ([1, 2³²)), rand.below(&st, n) ([0, n)), rand.shuffle(&st, xs) (Fisher-Yates, returns a new array).
    • time — wraps the clock() (monotonic ns) and now() (UNIX seconds) builtins. Stopwatch (value-semantic, no inout — a reading is just an int): sw := time.start(), then time.elapsed_ns(sw) / elapsed_us / elapsed_ms. Duration conversions ns_to_us / ns_to_ms / ns_to_s. Wall clock unix_secs() (named so, not now, to avoid shadowing the builtin and recursing). Blocking sleep sleep_ms(ms) / sleep_ns(ns) (a libc-only shim over nanosleep): a non-positive duration returns immediately, the sleep is *not* interruptible (it retries with the remaining time, so the full duration always elapses), and it parks the calling task only.
    • datetime — civil (proleptic Gregorian) calendar math over UNIX timestamps, all pure integer arithmetic. A DateTime struct (year/month/day/hour/minute/second/weekday, all UTC). from_unix(secs) and its exact inverse to_unix(dt); days_from_civil/civil_from_days/ weekday_from_days (the day-count core); weekday(y,m,d) (0=Sun..6=Sat), is_leap, days_in_month; now_utc() (the only non-pure fn — reads now()); formatting format_iso (YYYY-MM-DDTHH:MM:SS), weekday_name, month_name, pad2/pad4; and its inverse parsing parse_iso (wall-clock fields; T or space separator, trailing zone ignored) / parse_iso_tz (+HH:MM / -HH:MM / Z folded to the UTC instant), plus parse_clf / parse_clf_tz for the Common Log Format stamp (dd/Mon/yyyy:HH:MM:SS ±HHMM, as in Apache/nginx access logs) and month_num ("Jan".."Dec" → 1..12), all fail-closed via a year = -1 sentinel that ok(dt) checks. The core is UTC; timezone support is layered on — fixed offsets (from_unix_at, to_unix_at, format_iso_tz) in pure Tycho, plus DST-aware system/zone offsets via a small libc shim (local_offset, offset_at, now_local). IANA TZif zones live in core:tz. format_offset(offset_secs) renders a UTC offset as +HH:MM / -HH:MM.
    • tz — IANA TZif (RFC 8536) zones. parse_tzif(data, name) -> Result(Zone, TzErr) reads v1/v2/v3/v4 files, including the 64-bit block; offset_at(z, unix) and abbreviation_at(z, unix) binary-search transitions, fall back to the initial type before the first one, and apply the POSIX TZ footer after the last transition (including southern-hemisphere rules). Leap-second records are parsed into Zone.leaps as Leap{occurrence, correction}; leap_count(z), leap_at(z, i) and leap_correction_at(z, unix) expose them. Occurrences must increase and corrections must change by exactly one, so malformed records fail as Corrupt.
    • regex — POSIX extended regular expressions (ERE) over libc. compile(pat) -> ptr (opaque handle; ok/is_null to check), is_match, find / find_end (offset or −1), matched (first match substring). Capture groups of the first match by index (0 = whole match): ngroups, group_start / group_end (offset or −1), group(re, s, n) (substring), groups(re, s) (all groups as [string]). release frees the C-owned handle — the compiled pattern is C-malloc'd, not caller-managed, so call it when done.
    • http — an HTTP(S) client over libcurl, and the first module to declare an external dependency (corelib/http/deps → libcurl). get(url) -> ptr / post(url, body, content_type) -> ptr return an opaque response handle, or null on a transport failure (ok/is_null). status(r) (e.g. 200), body(r) (arena-copied), release(r) (the handle is C-owned). Convenience: get_body(url) / get_status(url) do the request and free the handle. The body is arena-copied via the FFI string-return, so a binary body with interior 0x00 truncates — body(r) is for text APIs; body_bytes(r) is the binary-safe sibling (interior NULs preserved). post(url, body, content_type) takes a string body and stops at the first interior 0x00; post_bytes(url, body, content_type) is its binary-safe sibling, taking bytes and sending the whole length. Tests are skipped where libcurl is absent.
    • textmatch — Lua-style patterns translated to POSIX ERE over core:regex. find(s, pattern, init) -> Option((start, end)), matches(s, pattern), gmatch(s, pattern) -> [string], and gsub(s, pattern, replacement) with %0..%9 capture references and %% for a literal percent. Supports %a/%c/%d/%g/%l/%p/%s/%u/%w/%x, ., [...], * + ?, ^ $ and captures. %bxy balanced matches, %f[set] frontier matches and non-greedy - use a native matcher; every other pattern keeps the POSIX ERE fast path.
    • xml — a self-contained XML parser and serializer. Node is Element(name, [Attr], [Node]) or Text(string); parse(s) -> Result(Node, XmlErr) accepts an XML declaration, comments, processing instructions, a DOCTYPE (skipped textually), attributes in either quote style, nested and self-closing elements, CDATA, and the five predefined entities plus decimal and hex character references. stringify(node) re-emits compact XML, escaping & < > in text and & < " plus tab/CR/LF in attributes. Queries are tag, attrs, attr(node, name) -> Option(string), children, text (a Text node) and text_content (all descendant text). Errors carry a byte offset: BadSyntax, Mismatch, BadEntity, TooDeep (256 levels) and Trailing. DTD-defined entities and namespace resolution are not implemented.
    • json — a recursive-descent JSON parser + serializer. The document is a value-semantic tree, the Json enum (JNull/JBool/JNum/JFloat/JStr/JArr/ JObj, objects as parallel key/value arrays). parse_checked(s) -> Result(Json, JsonErr) is the entry point new code wants — the grammar it accepts is exactly RFC 8259's and every refusal carries the byte offset that caused it (err_reason, err_offset, err_str). parse(s) -> Json is the lenient wrapper that throws the error away and returns JNull for the whole document. stringify(j) -> string (compact; escapes " \ and every control byte, \b \f \n \r \t where a short form exists). Typed queries: kind (the variant tag as a string), get(j, key) (object field, else JNull), at(j, i) (array element, else JNull), keys (object keys in order), len_of (array/object count or string length), as_num/as_str/as_bool/as_float/as_lexeme (payload with a zero-value default). Variants are constructible cross-package (json.JNum(1)). Round-trip fidelity: an integer that fits 64 bits is JNum and everything else — a fraction, an exponent, or an integer too large — is JFloat(value, lexeme) carrying the original digits, so stringify re-emits every accepted number byte-for-byte; object keys keep insertion order; a duplicate key resolves to its last value at the first key's position, so a parsed object holds each key once; a \uXXXX escape decodes to its UTF-8 bytes. Two limits: a number outside binary64's range (1e400) is refused rather than represented, and get returns JNull for both a null-valued member and an absent one — walk keys to tell those apart. err_at(code, off) builds a JsonErr for a given code and byte offset, for a caller layering its own parse step on top of this one.
    • cbor — CBOR (RFC 8949) encode/decode. Value is UInt(u64), Neg(int), Bytes, Text, Array, Map([Pair]), Tag(int, Value), Bool, Null, Undefined or Float; encode(value) -> bytes writes definite lengths, and decode(bytes) -> Result(Value, CborErr) accepts definite and indefinite strings/arrays/maps plus half, single and double floats. Tags are preserved but their contents are not interpreted. The decoder is depth-limited to 128 and reports Truncated, BadPrefix, TooDeep, Unsupported, OutOfRange or Trailing; integer values outside signed 64-bit are OutOfRange.
    • asn1 — DER/BER TLV for certificates, keys and protocol blobs. A Node is a Tag{cls, constructed, number} plus Primitive(bytes) or Constructed([Node]); parse(bytes) -> Result(Node, Asn1Err) accepts definite and BER indefinite constructed lengths, and encode(node) emits definite DER. Constructors: universal, sequence, set, make_bool, make_null, make_integer, make_octets, make_bit_string, make_oid, make_utf8, make_printable, make_ia5, make_utc_time, make_generalized_time, context_primitive, context_constructed. Readers: primitive, children, bool_value, int_value (signed 64-bit), octets, bit_string, text_value, oid. Errors are payload-free: Truncated, BadTag, BadLength, BadIndefinite, BadValue, BadOid, OutOfRange, TooDeep (128 levels) and Trailing.
    • csv — an RFC 4180 CSV parser + serializer. A document is rows of fields, [[string]]. parse(s) -> [[string]] handles quoted fields, the "" escape, embedded delimiters/newlines inside quotes, and LF / CRLF / lone-CR line endings; it fails closed (an unterminated quote parses leniently, never aborts). Bytes after a closing quote JOIN the field ("ab"cd is abcd). A trailing newline adds no empty row; a mid-file blank line is a row with NO fields. stringify(rows) -> string emits LF endings and quotes only fields containing the delimiter/quote/CR/LF (doubling internal quotes) -- parse/stringify round-trip. parse_delim/stringify_delim take an arbitrary single-byte delimiter (TSV is parse_delim(s, 9)); get(rows, r, c) is a bounds-safe cell read ("" if OOB).
    • markdown — a pragmatic Markdown → HTML renderer in pure Tycho. render(src) handles ATX headings, fenced code (HTML-escaped), blockquotes, unordered/ordered lists, thematic breaks, and paragraphs; inline **bold**, *italic*/_italic_, code , [text](url), ![alt](src). All text is HTML-escaped and unknown syntax degrades to escaped plain text (never a parse abort). Not full CommonMark (no nested lists, reference links, tables, or setext headings) — targets a blog/wiki. esc(s) is that HTML escaper on its own, for callers assembling markup around rendered output.
    • entity — HTML entity text: decode(s) handles the common HTML4 named entities plus decimal and hex numeric references (unknown names stay verbatim), and encode(s) escapes & < > " '.
    • base64 — Base64 (RFC 4648) encode/decode, plus encode_url (URL-safe -/_ alphabet, no padding). decode is lenient: it skips any non-alphabet byte (padding =, whitespace, newlines in wrapped Base64) and accepts both alphabets. Tycho strings are length-carrying and can contain interior 0x00 bytes, so decode preserves NULs as well as other decoded bytes. Use bytes when crossing a binary C API.
    • hxa — HxA 3D asset interchange, format v3. parse(data) -> Result(HxaFile, HxaErr) reads the node tree, metadata, geometry and images; write(file) -> Result(bytes, HxaErr) serializes it. Metadata helpers are meta_text, meta_i64, meta_f64, meta_node, meta_binary and meta_nested; layer helpers are layer_u8, layer_i32, layer_f32 and layer_f64; node helpers are node_meta, node_geometry and node_image. Accessors are layer_count, layer_u8_at, layer_i32_at, layer_f32_at, layer_f64_at, meta_i64_at, meta_f64_at and meta_node_at. HxaErr is BadMagic, UnsupportedVersion, Truncated, Corrupt or TooBig.
    • hex — hexadecimal encode (lowercase) / encode_upper / decode, two digits per byte, plus is_valid (strict: even length, all hex digits). decode is lenient (skips any non-hex byte, so de:ad:be:ef and spaced/newlined hex work, either case) and reuses core:char's hex_val. Decoding "00" returns a one-byte string containing NUL.
    • base32 — RFC 4648 Base32 (A-Z2-7): encode (padded) and encode_no_pad, plus decode, which accepts padded and unpadded input and reports BadLength, BadChar or BadPadding instead of returning partial bytes.
    • endian — width-checked reads and fresh writes for binary framing. get_u16_le/get_u16_be, get_u32_le/get_u32_be, get_u64_le/get_u64_be return Result(..., EndianErr) (Short when the window is too small); put_u16_le/put_u16_be, put_u32_le/put_u32_be, put_u64_le/put_u64_be return the encoded bytes.
    • varint — LEB128: put_u64 and get_u64 (value plus bytes consumed), put_i64 and get_i64 (zigzag signed). get_* fails with Truncated or Overflow, never a partial value.
    • pem — RFC 7468-style PEM blocks. Block{label, data}; encode(label, data) wraps Base64 at 64 columns, and decode(s) returns the first block and ignores text outside its markers. PemErr separates NoBlock, Unterminated, BadLabel (END label differs) and BadBase64.
    • url — URL percent-encoding (RFC 3986). encode is component-style (like JS encodeURIComponent — everything but unreserved A-Z a-z 0-9 - _ . ~ becomes %XX, uppercase, space → %20); encode_form / decode_form use the x-www-form-urlencoded convention (space ↔ +); decode decodes %XX (leaving +). decode is lenient (a % not followed by two hex digits is emitted literally) and reuses core:char's hex_val. %00 produces an interior NUL byte in the returned string.
    • uuid — version-4 UUIDs (RFC 4122) plus the nil UUID and helpers. v4(&st) draws 16 bytes from core:rand (state threaded by inout) and sets the version/variant bits; it is not unguessable — use crypto.random_hex for a token. nil(), parse(s) -> [int] (16 bytes, lenient on separators, [] unless exactly 32 hex digits), format(bytes) -> string (canonical 8-4-4-4-12), is_valid (strict), version (the version nibble, -1 if invalid). v1 and the name-based v3/v5 are out of scope. Zero bytes survive formatting.
    • hash — non-cryptographic hashes for hash tables / checksums / dedup (NOT for cryptographic use): fnv1a_32, djb2, sdbm, crc32, and xxHash xxh32(s, seed) / xxh64(s, seed). The old 32-bit helpers remain. Also crc16_ccitt (CRC-16/CCITT-FALSE), crc64_ecma (CRC-64/ECMA-182), adler32, murmur3_32(s, seed) and fnv1a_64. security): fnv1a_32, djb2, sdbm, and crc32 (IEEE/zlib, bit-by-bit), plus to_hex (8-digit lowercase). All return a non-negative int in [0, 2^32). Matches published vectors: crc32("123456789") = cbf43926, fnv1a_32("foobar") = bf9cf968. For a hash of any hashable value (struct/tuple/array, not just a string) use the generic builtin hash(x) — deterministic (the same value hashes the same on every run and machine), full 64-bit as a signed int (builtins §29.7).
    • md5 — the MD5 message-digest (RFC 1321): hex(s) (32-char lowercase digest) and digest(s) (16 raw bytes). MD5 is broken for security (use it for checksums / content-addressing / interop, never passwords or signatures). Bit-exact against the RFC 1321 suite (md5("abc") = 900150983cd24fb0d6963f7d28e17f72).
    • sha256 — the SHA-256 hash (FIPS 180-4): hex(s) (64-char lowercase digest) and digest(s) (32 raw bytes). A real cryptographic digest — fine for checksums, content addressing, and HMAC building blocks (not a standalone password hash; use a KDF for that). Bit-exact against NIST vectors (sha256("abc") = ba7816bf…f20015ad). For input too large to hold at once there is a streaming form: init() gives a State, update(&st, data) folds in each chunk, and final_hex(&st) closes it and returns the digest — the same answer hex(s) gives for the concatenation. hex_bytes(b) hashes one complete bytes buffer through the runtime C fast path (SHA-NI, OpenSSL, or scalar) and returns the same 64-char digest.
    • dynlib — shared-library loading and typed C function-pointer calls: open(path) -> Result(ptr, DynErr), symbol(h, name) -> ptr (null when absent), and close_lib(h). Call a resolved C function with call_i32_0/call_i32_1/call_i32_2/call_i32_3, call_i64_1, call_f64_1, call_i32_str, call_i32_str_str, call_ptr_i64, call_void_ptr or call_ptr_1. Windows uses LoadLibraryA/GetProcAddress. apply_i32_i32(f, a, b) passes a Tycho function to C: the compiler emits a C-ABI trampoline for a named non-capturing function with scalar/ptr parameters and a scalar/ptr/void result. Closures and function variables are not accepted as C callbacks.
    • x509 — X.509 certificate inspection and verification over OpenSSL (deps: openssl). parse_pem/parse_der return a Certificate handle; subject, issuer, serial, not_before/not_after (UNIX seconds), is_valid_at(c, secs), verify_hostname(c, host) (SAN DNS with CN fallback), and verify_chain(c, ca_pem, host) against one trusted CA. free(c) releases the handle exactly once.
    • bignum — arbitrary-precision integers in pure Tycho (sign + base-10⁹ limb array), value-semantic: from_int/from_str/to_str/to_int, add/sub/mul/divmod/div/ mod/pow, abs/neg/cmp/is_zero.
    • decimal — arbitrary-precision base-10 fixed point, composed on core:bignum (a Big coefficient × 10⁻ˢᶜᵃˡᵉ), so decimal fractions are exact (0.1 + 0.2 == 0.3): from_int/from_str/to_str, add/sub/mul (exact), cmp, neg/abs/is_zero, from_str_checked(s) -> Result(Decimal, DecErr) — the bare from_str fails open ("1.5x" is 0.15), so use the checked one on anything a user or a file supplied — rescale (truncating). Division takes its policy from the caller: div(a, b, scale, mode) -> Result(Decimal, DivErr), where mode is half_up() (ties away from zero) or toward_zero() (agrees with rescale) — there is no default, because there is no correct one. A zero divisor, a negative scale and an unknown mode are each an Err.
    • crypto — the security-grade module, a C-shim over OpenSSL libcrypto (see C-shim modules; needs the OpenSSL dev package). Where the pure-Tycho sha256/md5 are for non-adversarial integrity, this is what to reach for when an attacker is in the threat model: CSPRNG (random_hex), sha1/sha256/sha512/ sha3_256/sha3_512 of binary, extendable-output shake128/shake256(msg, outlen), blake2b/blake2s, hmac_sha256/hmac_sha512, pbkdf2_sha256, hkdf_sha256(ikm, salt_hex, info_hex, outlen) -> ptr (derived key handle), constant-time ct_equal, ChaCha20-Poly1305 AEAD (aead_encrypt/aead_decrypt, "!err" on auth failure), AES-GCM (aes_gcm_encrypt/aes_gcm_decrypt, 16/24/32-byte keys, 12-byte nonce, ciphertext plus 16-byte tag), AES-CTR (aes_ctr, 16-byte counter block), AES-CBC (aes_cbc_encrypt/aes_cbc_decrypt, no padding, input length a multiple of 16), Argon2id (argon2id(password, salt_hex, iterations, memcost, lanes, dklen) returning a key handle), Ed25519 (ed25519_pubkey/sign/verify), X25519 (x25519_pubkey/shared), and RSA PKCS#1 v1.5 with SHA-256 (rsa_key_from_pem, rsa_pubkey_from_pem, rsa_key_random(bits), rsa_key_bits, rsa_key_to_pem, rsa_pubkey_to_pem, rsa_key_free, rsa_sign_sha256, rsa_verify_sha256). ECDSA P-256/SHA-256 uses the same shape: ecdsa_key_from_pem, ecdsa_pubkey_from_pem, ecdsa_key_random, ecdsa_key_bits, ecdsa_key_to_pem, ecdsa_pubkey_to_pem, ecdsa_key_free, ecdsa_sign_sha256, ecdsa_verify_sha256. Post-quantum ML-DSA signatures are mldsa_key_random(level) (44/65/87), mldsa_key_from_pem, mldsa_pubkey_from_pem, mldsa_key_to_pem, mldsa_pubkey_to_pem, mldsa_key_free, mldsa_sign, mldsa_verify. ML-KEM encapsulation is mlkem_key_random(level) (512/768/1024), mlkem_key_from_pem, mlkem_pubkey_from_pem, mlkem_key_to_pem, mlkem_pubkey_to_pem, mlkem_key_free, mlkem_encapsulate(pub) -> Result(Encapsulated, KemErr), mlkem_ciphertext, mlkem_shared_secret, mlkem_free and mlkem_decapsulate(key, ciphertext). Pure Tycho arithmetic cannot promise constant-time behavior, so these primitives bind OpenSSL rather than reimplementing them. Every value (keys, nonces, ciphertext, signatures, digests) crosses as lowercase hexadecimal text at this interface; use core:hex to convert byte buffers. Checked against independent known-answer vectors (RFC 4231 HMAC, RFC 7914 PBKDF2, RFC 8439 ChaCha20-Poly1305, Ed25519/X25519). Keys are opaque handles — the lifecycle first: key_random(n) -> ptr makes one from the CSPRNG, key_from_hex(hex) -> ptr imports one, key_export_hex(k) -> string exports it, key_len(k) -> int is its byte length, and key_free(k) releases it. That handle is what aead_encrypt/aead_decrypt take. The signature keys have their own constructors — ed25519_key_from_seed(seed_hex), then ed25519_sign(key, msg_hex) -> string and ed25519_verify(pub_hex, msg_hex, sig_hex) -> bool — as does key agreement: x25519_key_random(), x25519_key_from_secret(secret_hex), and x25519_shared(my_key, their_pubkey_hex) -> ptr, whose result is a key handle ready for the AEAD.
    • result — the Result / Option collapses, generic over $T and $E: unwrap_or(r, fallback), is_ok(r), is_err(r), err_or(r, fallback), map_err(r, replacement), map_err_with(r, f), and some_or(o, fallback) / is_some(o) for the Option half. or_return unwraps a Result only inside a function that itself returns a compatible Result, so a main(), or a handler that returns a Response, needs another way: err_or plus == asks *which* failure happened without writing a match at all — a one-line if. map_err(r, replacement) re-labels the error so or_return carries it — req := result.map_err(httpd.read_request(fd), net.Failed) or_return — at the cost of the original cause. map_err_with(r, f) is its cause-preserving sibling — identical job and argument order, except f receives the Err payload and builds the replacement from it, so a Syntax(7) arrives as FromParse(7) rather than as a constant.     • toml — a TOML v1.0-subset parser: parse(s) -> Result(Value, string) (fail-closed), a recursive Value enum (TStr/TInt/TFloat/TBool/TArr/TTable; tables are parallel keys/values arrays), and get(t, "a.b.c") -> Option(Value) / keys(t). get accepts quote-aware path segments for keys containing dots.     • log — a leveled logger, state threaded like core:rand's: l := log.init(log.level_info(), false), then log.debug/info/warn/error(&l, msg) — each prints [level] message, dropping messages below the logger's level; to_stderr selects stderr over stdout.     • i18n — GNU gettext MO catalogs. parse_mo_from_bytes(data) -> Result(Translation, I18nErr) accepts both byte orders; get(t, key) returns the singular translation (or the key when absent), get_n(t, key, n) selects the English one/other plural form, and header(t) is the catalog header.     • io — filesystem helpers over the read_file/write_file/list_dir builtins. read(p) — fail-open: "" for a missing file, an unreadable one and a genuinely empty one alike, so prefer read_text(p) -> Result(string, IoErr) or read_bytes(p) when the difference matters — write(p, s) (truncate, returns false if unopenable) with checked sibling write_text(p, s) -> Result(void, IoErr), append(p, s) (no read-rewrite) and append_text(p, s) -> Result(void, IoErr) (the same, with the error channel), read_lines(p) / write_lines(p, lines) (newline-terminated round-trip) with checked sibling write_lines_checked(p, lines) -> Result(void, IoErr), list(p) (entry basenames) and list_checked(p) -> Result([string], IoErr) (which distinguishes an empty directory from an unreadable one, where list cannot), walk(root) -> Result([string], IoErr) (every path below root, depth-first with entry names sorted, root excluded; symlinked directories are reported but not followed, and an unreadable directory fails the whole walk instead of silently dropping that subtree), rename(src, dst) -> Result(void, IoErr) (atomically replaces a destination on the same filesystem), lock_exclusive(p) -> Result(bool, IoErr) is a nonblocking process-lifetime lock (Ok(false) means busy; the OS releases it when the process exits), exists(p) (one stat, not a listing of the parent; false means "stat could not say yes", so it fails closed). For inputs too large to slurp, a bounded-memory streaming line reader over a libc shim: open_lines(p) -> Result(LineReader, io.IoErr) → read_line(r) (Some(line) / None at EOF; embedded NUL bytes are preserved) → close_lines(r). A LineReader is opaque, and the opener reports *why* it failed: BadPath for an interior NUL, else NotFound / IsDir / Failed. There is no defer, so close_lines is the caller's to make. Plus fold_lines(p, init, f) — peak memory is O(longest line), not O(file). read_bytes(p) -> Result(bytes, io.IoErr) reads a whole file as raw bytes (binary-safe); an empty file is Ok with zero bytes, a missing path is Err(NotFound) and a directory is Err(IsDir) — three outcomes a single empty bytes would collapse. read_link(p) -> Result(string, io.IoErr) reads a symlink's target text — a dangling link is still Ok; on Windows a reparse point exposes no target string, so a path that exists is Err(Failed) and a missing one is Err(NotFound). read_stdin_bytes() -> Result(bytes, io.IoErr) reads all of stdin as raw bytes and keeps EOF (Ok, possibly empty) distinct from a read failure (Err(Failed)); stdin is exhausted afterwards and Windows switches the stream to binary mode. The variants are payload-free, so == and a nested Err(io.IsDir) arm both work. Three helpers resolve list's empty-directory ambiguity: is_dir(p) -> Result(bool, io.IoErr), and make_dir(p) / remove(p) — one entry each, never recursive — answering Ok(true) for "changed it" and Ok(false) for "already how you asked" (EEXIST on a directory is Ok(false), on anything else Err(Exists); remove refuses a non-empty directory with Err(Failed)). make_dir_all(p) is the recursive form under a separate name on purpose: no corelib name is secretly recursive. There is deliberately no remove_all: a recursive delete is the one where a wrong path costs unrecoverable data. Three more answer what an HTTP server needs: mtime(p) -> Result(int, io.IoErr) (whole seconds; a directory is Ok), size(p) -> Result(int, io.IoErr) (a length without reading; a directory is Err(IsDir)), and read_at(p, off, n) -> Result(bytes, io.IoErr) (allocates only what the file holds past off, so a length off the wire cannot over-allocate; past EOF is Ok with zero bytes). A procfs-style pseudo-file whose st_size is 0 but which yields bytes is the exception: use read_bytes; size/read_at see 0. The writers that can only succeed or fail — write_bytes(p, b), write_at(p, off, b), set_mtime(p, secs), rename(src, dst) and sync(p) — return Result(void, io.IoErr), so io.write_bytes(p, b) or_return is a statement and a match arm is Ok():. stat(p) and lstat(p) return Result(Stat, io.IoErr) with kind: FileKind (KindFile / KindDir / KindSymlink / KindFifo / KindSocket / KindDevice / KindOther), size, mtime, inode and device; stat follows symlinks and lstat does not. same_file(a, b) -> Result(bool, io.IoErr) compares device + inode (volume + file index on Windows), so two names of one hard link answer true. flush_stdout() -> bool flushes the runtime's buffered stdout; use it when a pipe reader must see a startup line before the process exits (print/println are block-buffered when stdout is not a terminal). Its checked sibling flush_stdout_checked() -> Result(void, IoErr) reports the refusal. Nothing aborts.
    • os — is_windows() reports the host family at runtime — run external commands via a libc-only FFI shim (no deps, nothing to install). os.system(cmd) runs cmd through the shell with stdout/stderr inherited, returning its exit code (0..255, 128+signal if killed, -1 if the shell won't start); os.run(cmd) additionally captures stdout into Output{code, out}. cmd is a /bin/sh -c line — shell metacharacters are active, so quote untrusted input yourself. On iOS there is no shell: system and run fail closed (-1, empty output), while the array-argv exec family still uses posix_spawnp. os.exec(argv) / os.exec_out(argv) are the array-argv pair and take a [string]: no shell is started at all, so an argument of "; rm -rf /" is one ordinary argument rather than a second command — prefer them whenever the arguments are not compile-time constants. Neither replaces the calling process despite the name — both spawn, wait, and return. Same exit-code contract; exec_out captures stdout. They fail closed with -1 on an empty argv, more than 4096 entries, an allocation failure mid-build, or a program that cannot be spawned — never a silent fallback to the shell. Implemented on both platforms — POSIX posix_spawnp, Windows CreateProcess (never cmd.exe) — but a program that parses its own command line by other rules (a .bat/.cmd file) can still read it differently, so don't hand a batch file untrusted argv. os.exec_capture(argv) -> Capture{code, out, err} is exec_out with stderr kept separate; both pipes are drained concurrently, so a child cannot deadlock by filling one stream before the other. Same no-shell, fail-closed -1 contract with both strings empty. The environment and process-location surface is fail-closed too: env(name) -> Option(string) distinguishes unset (None) from set-to-empty (Some("")); set_env(name, value) and unset_env(name) return Result(void, OsErr) and refuse an empty name, an embedded =, or a NUL value (BadName / BadValue). cwd() / chdir(p) round-trip the working directory, with NotFound / Denied / Failed kept apart; pid() and hostname() -> Option(string) report the process identity; home_dir() tries HOME, then USERPROFILE, then HOMEDRIVE+HOMEPATH; temp_dir() tries TMPDIR, TEMP, then TMP, and falls back to /tmp on POSIX or . on Windows. chmod(path, mode) -> Result(void, OsErr) sets permission bits (Windows maps to the read-only bit and ignores the rest), umask(mask) -> int returns the previous mask, and uid/euid/gid/egid/ppid report identity (-1 on Windows, which has no numeric ids). cache_dir, config_dir and data_dir follow XDG_* on POSIX and %LOCALAPPDATA%/%APPDATA% on Windows. platform() reports Linux/Windows/MacOS/Android/IOS/Other; is_linux, is_macos, is_android and is_ios are the predicates. create_temp_file(prefix) and create_temp_dir(prefix) return fresh paths in the system temp directory (the prefix may not contain a path separator), and user_name() is the account login name where the OS exposes one. exit(code) and die(msg) are language builtins, not core:os members; see builtins. pipe() returns (read_fd, write_fd); read_fd(fd, max) and write_fd(fd, data) cover descriptor I/O and close_fd(fd) releases one.
    • net — TCP/UDP sockets over a libc-only FFI shim (POSIX sockets; no deps, nothing to install). The transfer calls block; readiness does not. read/write/connect block, so a worker-per-connection server still has its worker count as a ceiling on concurrent connections — size the pool for the concurrency needed and put a timeout on the socket. But two calls take a deadline and do not block on the peer: wait_readable(fds, ms) -> Result([int], NetErr) names exactly the descriptors that are ready (or an empty list when ms elapses), and accept_wait(fd, ms) -> Result(int, NetErr) waits for one inbound connection with a timeout. close_fd(fd) releases a descriptor obtained this way. Every fallible TCP call returns Result(T, net.NetErr): listen/accept/connect/port_of give Result(int, …), peer_addr(fd) gives Result(string, …) — the connected peer's address as text, the field a real access log leads with. write gives Result(int, …) (bytes sent; Err(Timeout) once a send deadline expires), read gives Result(bytes, …). Payloads are binary-safe bytes. NetErr is Eof / Timeout / Failed, all payload-free so a single cause can be tested with == without opening a match at all — or, inside one, with a nested Err(net.Timeout) arm (§14.3.1). read distinguishes a clean hangup (Err(Eof)) from an expired receive deadline (Err(Timeout)) from a hard error (Err(Failed)) — three answers a bare empty bytes would collapse into one. set_read_timeout_ms(fd, ms) arms a receive deadline and stays a plain bool — one failure, one cause; ms <= 0 restores the blocking default and false means the option could not be set (the socket keeps blocking). The send-side set_write_timeout_ms(fd, ms) has the same contract and makes a stalled write answer Err(Timeout). The UDP calls keep their sentinel forms (udp_bind/udp_send/udp_read) and gain checked siblings udp_bind_checked / udp_send_checked / udp_read_checked. The checked read is the one that matters: a zero-length datagram is Ok([]), distinct from Err(Timeout) and Err(Failed), while the sentinel udp_read still returns empty bytes for all three. resolve(host) -> Result([string], NetErr) returns the numeric IPv4/IPv6 addresses from getaddrinfo; an interior NUL is BadAddr, a lookup failure is Failed. Socket options are plain booleans: set_reuse_addr, set_nodelay, set_keepalive, set_broadcast, set_nonblocking (POSIX fcntl, Winsock ioctlsocket). unix_listen(path) / unix_connect(path) are POSIX Unix-domain stream sockets (Windows answers Failed). interfaces() returns Interface{name, addr} records from getifaddrs (POSIX; Windows Failed). Address text is handled without a resolver: parse_ip4/format_ip4, parse_ip6/format_ip6 (including :: compression and a trailing IPv4 part), parse_endpoint/join_endpoint (host:port, IPv6 in brackets) and is_ip4/is_ip6; Ip4, Ip6 and Endpoint are plain value structs. Prefixes are addr/N: parse_ip4_prefix/parse_ip6_prefix and format_ip4_prefix/format_ip6_prefix (a bare address is /32 or /128); prefix_network_ip4/prefix_network_ip6 clear host bits and prefix_contains_ip4/prefix_contains_ip6 test containment. DNS response packets can be parsed without a resolver: parse_dns(data) -> Result([DnsRecord], DnsErr) returns the ANSWER section, with DnsRecord{name, ttl, data} and DnsData variants Mx(DnsMx), Txt(string), Srv(DnsSrv) and Other(type). parse_mx, parse_txt and parse_srv filter to one record type. Name compression, MX preference, TXT character-string chunks and SRV priority/weight/port are handled; DnsMx{preference, host} and DnsSrv{priority, weight, port, target} carry the decoded fields. build_query(name, qtype, id) constructs a recursive query; dns_query_on sends a built query on a bound UDP descriptor, dns_query binds an ephemeral socket and uses a 2s read timeout, and query_mx/query_txt/query_srv return the filtered records. DnsErr adds Network for a send failure, timeout or short datagram. dns_query_tcp sends the same query over a length-prefixed TCP stream, and dns_query_fallback_on retries over TCP when the UDP response has the TC bit set; dns_query uses that fallback automatically.
    • nbio — readiness polling and completion loops. poll(fds, events, timeout_ms) -> Result([Ready], NbioErr) waits on each fd with an event mask of READ/WRITE (Ready{fd, events} carries the revents mask; a negative timeout waits forever). POSIX uses poll(2), Windows WSAPoll; BadArg covers a length mismatch or timeout below -1. CompletionLoop adds loop_new, loop_free, loop_add, loop_modify, loop_remove, loop_post and loop_wait(timeout_ms, max_events) -> Result([Completion], NbioErr), where Completion{fd, events, user} carries fd == -1 for a posted completion. Linux uses epoll, BSD/macOS kqueue, Windows IOCP; posted completions are thread-safe.
    • httpd — a minimal HTTP/1.1 server toolkit over core:net (no external dependency — net is libc-only). The request/response plumbing is pure Tycho; the accept loop is the caller's. parse_request(raw) -> Result(Request, httpd.ReqErr) (method/path/version, case-insensitive header(r, name), has_header(r, name) distinguishes an absent field from a present-but-empty one, honors Content-Length; Err(Malformed) on a malformed request line); response(status, body: bytes) (standard reason phrase) / response_reason(status, reason, body: bytes) (a custom phrase for a status the table does not carry) / text_response(status, body: string) / with_header(r, k, v) / with_body(r, b) / render_head(r) -> string / render(r) -> bytes (Content-Length and a default text/plain Content-Type are added automatically); and the socket glue read_request(fd) -> Result(Request, httpd.ReqErr) (reads until the header terminator, then exactly Content-Length body bytes, bounded so a hostile peer can't spin) — its Err says which failure, Malformed / Closed / Timeout / Failed / TooLarge, so a server can answer 400 to garbage while hanging up silently on a disconnect / read_request_capped(fd, cap) -> (Result(Request, httpd.ReqErr), string) (the same read with a caller byte budget — reaching it with no header terminator is Err(TooLarge) — plus every byte read as the second tuple element, so an access log can name a request that would not parse; read_request is this with cap = MAX_REQUEST) / read_request_deadline(fd, cap, deadline_ms) (the same again, with a deadline on the whole head-and-body rather than on one read) / read_request_resume(fd, cap, deadline_ms, have) (the same again, resumed: have is the buffer a previous call returned beside Err(Timeout) on this same fd, so an event loop can give a slow head a short slice per visit. Hand the buffer back only after Err(Timeout) and drop it on every other outcome — carrying it past a completed request would splice two heads together; cap bounds have plus everything read after it) / write_response(fd, r) -> Result(int, net.NetErr) (Ok = total bytes written; the same error type net.write returns, so or_return propagates a failed send). Binary-safe bodies — Request.body and Response.body are bytes, so a PNG or a font round-trips byte for byte; headers stay string (ASCII by spec). content_type(path) maps a file extension to a MIME type — .html .htm .css .js .mjs .json .txt .xml .svg .png .jpg .jpeg .gif .webp .ico .woff .woff2 .pdf .wasm — and an unknown extension yields application/octet-stream, never text/plain. Keep-alive: connection_close(req) (HTTP/1.1 defaults open, 1.0 defaults closed, an empty bad_request() always closes) and with_connection(r, alive); pair it with net.set_read_timeout_ms so an idle peer cannot pin a worker. CRLF is built with chr(13) (tycho strings have no \r escape). Framing is refused, never guessed, by all three read entry points: any Transfer-Encoding field and an empty/invalid Content-Length are refused — chunked bodies are not decoded — a Content-Length that is not a plain decimal, two Content-Length headers that disagree, or Content-Length together with Transfer-Encoding, are each Err(Malformed), and the connection must not be reused. A framed size past cap is Err(TooLarge) *before* the body is read; a body shorter than its own Content-Length is Err(Closed). Pipelining is not supported. Exactly the bytes this request framed are parsed; anything the peer sent past them is discarded with the buffer, so a client that pipelines loses every request after the first. What matters is that the leftover is never glued onto this request's body. The request-shaping helpers the server layer calls are public too: reason_phrase(status), bodyless(status) (whether a status may carry a body at all — 204/304 and the 1xx range), content_length_conflict(r) (a request carrying both Content-Length and Transfer-Encoding), parse_len(s) -> (int, bool) (a length header with its validity flag), has_ext(path, ext), and crlf().
    • cli — command-line argument parsing, pure string math. parse(argv) -> Cli sorts the vector into three buckets: --key=value options, boolean flags (--flag, and short clusters -abc → a/b/c), and positionals (everything else, plus everything after a bare --). Values always attach with =, so parse needs no schema of which options take a value — --verbose is unambiguously a flag and --out=x unambiguously an option. argv() is the builtin args() with args()[0] (the program path) dropped, which is what parse wants, so a program's whole front door is c := cli.parse(cli.argv()). Pass a vector to parse yourself and it is used as given; the skip lives in argv(), not in parse. parse_spec(argv, valued, boolean) -> Cli is the schema-carrying form, and it is what buys the space-separated Unix spelling --root DIR: valued and boolean list long option names and short flag letters without dashes, the same spelling get/flag take. It is an addition, not a migration — parse is unchanged and every =-attached spelling means the same thing in both. Its rules: a valued name consumes the next argument as-is (so --root --port sets root to --port) or lands in missing(c) if there is nothing after it; a boolean name spelled --flag=v sets the flag and drops v; a name in neither list, and a short cluster containing a letter in neither, land in unknown(c) as written. parse_checked(argv, valued, boolean) -> Result(Cli, CliErr) is parse_spec that refuses instead of sorting: Err(Unknown(tok)) or Err(NoValue(name)) on the first offending token, so a program cannot forget to look at unknown/missing. No short option takes a value (-p 80 is not a spelling this package has — it would make -abc ambiguous); use --port 80. Accessors: get(c, key, default), has(c, key), flag(c, name) (long or short), positionals(c), count(c), missing(c), unknown(c). Uses parallel arrays, not maps.
    • raster — pure-Tycho raster image codecs, BMP, QOI and TGA, with no external dependency (unlike core:image's libpng-backed PNG). An Image is 8-bit RGBA (4 bytes/pixel, row-major, top-to-bottom); pixel data is bytes. encode_bmp/decode_bmp (writes 32-bit BGRA, bottom-up, uncompressed; reads 24- or 32-bpp BI_RGB), encode_qoi/decode_qoi (all six QOI chunk types), and encode_tga/decode_tga (uncompressed 24/32-bpp, top-down write; reads type 2 and RLE type 10, top-down or bottom-up; color-mapped and grayscale TGA are refused), encode_ppm/decode_ppm (P6), encode_pgm/decode_pgm (P5) and encode_pbm/decode_pbm (P4), with comments, CRLF and any maxval 1..255 scaled to 8-bit (PGM writes luma, PBM thresholds at 128). All round-trip losslessly; the decoders fail closed to a 0×0 Image on a malformed / truncated / wrong-format input (check width > 0). too_big(w, h) is the decode guard in front of every codec here: it answers whether a declared width and height would allocate past the ceiling.
    • terminal — ANSI output and terminal state. Pure escape builders: reset, bold, dim, italic, underline, reverse, fg/bg (256 colours), fg_rgb/bg_rgb, clear_screen, clear_line, move(row, col), hide_cursor, show_cursor. Host queries: is_tty(fd), size(fd) -> Option((cols, rows)), supports_ansi(fd). raw_enter(fd) saves the terminal mode and returns an opaque handle (null on a non-terminal), raw_leave(h) restores and frees it, read_byte(fd) -> Option(int) reads one byte from a raw descriptor, and parse_key(bytes) -> Key decodes printable UTF-8, Enter/Tab/Backspace/Escape and the common CSI arrows/Home/End/Delete. Cursor queries: parse_cursor_response(bytes) -> Option(CursorPos) accepts ESC[row;colR and ESC[?row;colR; cursor_query(out_fd, in_fd, timeout_ms) sends DSR and waits for the reply; cursor_position(fd) is the one-fd convenience form. TermErr is BadArg, NotTty, Timeout, BadResponse or Failed. Windows consoles read the cursor directly; non-console Windows ttys (MSYS pty) use the ANSI fallback.
    • signal — clean shutdown on SIGTERM/SIGINT, and nothing else: a libc-only shim with nothing to install and nothing to link. on_shutdown(fd) -> bool installs one handler for both signals whose only action is to shut down the listening socket, so every thread blocked in net.accept(fd) is released with Err(Failed) and the program winds down through the path it already has. It fails closed: false means the handler was not installed and the default disposition (die on SIGTERM) still stands. shutdown_requested() -> bool reads the flag the handler set, for a loop that wants to stop for a reason other than a failed accept. Order matters — call on_shutdown *after* net.listen, with the listening fd, and *before* the accept loops start. There is deliberately no signal.on(sig, handler): no Tycho code runs in handler context, so a general handler API would need answers about allocation, tasks, and signal delivery that do not exist here. Waking a blocked accept() this way is a Linux behavior rather than a portable guarantee, and connections still in the backlog are dropped rather than drained. For a server that must report which connections it dropped, register_conn(slot, fd) records a live descriptor against a slot and retire_conn(slot) clears it.

    C-shim (FFI-backed) modules

    A core module can wrap a C library via FFI. Drop a <module>/<module>_shim.c next to the .ty; the transpiler auto-compiles and links it on import "core:<module>" (no --shim needed). The .ty declares the shim's functions with extern fn (and extern "Lib" fn auto-adds -lLib for an external library; core:regex needs none — POSIX regex is in libc). Opaque handles cross as ptr (carried by value, never dereferenced or caller-managed — null / is_null). tychoc links a module's shim automatically — no --shim needed for a corelib package.

    Freeing a shim handle

    A ptr handle is not affine, so nothing in the type system stops a caller freeing one twice or reading one after free. core:crypto, core:tls and core:http guard that at run time by keeping the handle's own header: the payload is released on free, so a second free or a later use aborts by name (for example tycho: double free of crypto key handle) rather than reading freed memory. The kept header is never reused for a new handle, so a stale handle can never alias a later one; it is also never freed, so each freed handle keeps a small header for the life of the process — nothing measurable for a one-shot program, and the figure for a long-lived one to check is in the design note.

    core:image uses a monotonically numbered handle into a live set instead: releasing an image frees its header and pixels, and a stale ID is rejected before anything is read. That keeps the same double-free/use-after-free diagnosis without retaining one header per decoded image.

    External dependencies (C-shim deps)

    A shim that needs a system library beyond libc — one with headers to find and a link flag that varies by platform — declares it in a corelib/<module>/deps manifest: pkg-config package names, one per line (# comments and blank lines ignored). For example corelib/http/deps is just libcurl.

    The deps-backed modules are http (libcurl) and crypto (libcrypto), documented above, plus four more:

    • gfx — SDL3 window/render/audio (deps: sdl3); see the package entry above.
    • lz4 — a pure LZ4 block codec, no external library. compress(src) is greedy and emits a valid block; decompress(src, out_len) needs the original size because a block does not carry it, and compress_bound(n) is the safe output bound. Errors are Truncated, BadOffset, OutputTooSmall and BadSize. Frames and checksums are not implemented.
    • compress — gzip (RFC 1952) compress/decompress over zlib (deps: zlib). Streaming: deflater_new(level)/deflate_chunk/deflate_finish/deflater_free and inflater_new/inflate_chunk/inflate_finish/inflater_free; chunks may produce empty bytes, and the inflater auto-detects gzip or zlib wrappers. compress(bytes) -> bytes; decompress(bytes) -> Result(bytes, ZErr) and raw_decompress likewise, where ZErr is Corrupt / Truncated / Failed / TooBig (decompressed output exceeds its limit). Ok with length 0 is a real empty payload, distinct from every failure. On a RAW deflate stream Truncated also covers "not a deflate stream": there is no wrapper or checksum to tell those apart. compress is byte-deterministic and callers may rely on it: for one zlib build it is a pure function of its input — same bytes in, byte-identical bytes out. The compressed *length* is a zlib tuning detail — it is not stable across zlib versions. raw_compress(data) is the same deflate without the gzip framing, for callers that supply their own container. Each decompression is capped at 1 GiB (or the zlib uInt limit when lower). bzip2 is loaded at run time (libbz2.so.1, libbz2.dylib, libbz2.dll); bzip2_available() reports whether it loaded, and bzip2_compress(data) / bzip2_decompress(data) return Result(bytes, ZErr). There is no hard link dependency on libbz2. Reversible filters: delta_new(distance)/delta_encode/delta_decode, bcj_new(arch, start_offset)/bcj_encode/bcj_decode for X86, PowerPC, IA64, ARM, ARM_Thumb, SPARC, ARM64 and RISCV, and swap2/swap4. FilterErr is BadDistance or BadAlignment. PPMd is vendored public-domain C (7-Zip's PPMd7 var.H and PPMd8 var.I), so there is no runtime 7-Zip dependency. PpmdProps{variant, order, mem_size, restore}; ppmd_level_properties(variant, level, input_size) maps 0..9 to the same presets as 7-Zip; ppmd_decode_props_7z/ppmd_encode_props_7z handle the 5-byte 7z properties and ppmd_decode_props_zip/ ppmd_encode_props_zip the 2-byte ZIP method 98 properties. ppmd_decompress_7z(data, props, expected_size) and ppmd_compress_7z(data, props) are the raw var.H stream 7z stores; ppmd_decompress_zip/ppmd_compress_zip are the var.I stream used by ZIP method 98. The encoders are byte-identical to 7-Zip for the same properties. PKZIP legacy methods are also vendored public-domain C (hwzip): unshrink(data, expected_size) and shrink(data) for method 1, expand(data, factor, expected_size) and reduce(data, factor) for methods 2-5 (factor 1..4), and explode(data, large_window, literal_tree, expected_size)/implode(data, large_window, literal_tree) for method 6. CodecErr is CodecInvalidProps, CodecBadOption, CodecCorrupt, CodecTruncated, CodecTooBig or CodecFailed. Deflate64 (ZIP method 9) is a raw stream codec: deflate64_decompress(data, expected_size) uses zlib's infback9 decoder and accepts the full 64 KiB window and extended length/distance codes; deflate64_compress(data) emits a valid Deflate64 stream through zlib's raw-deflate path and verifies it with the same decoder. The encoder uses the standard 32 KiB/257-byte subset, so it does not exercise the extended 64 KiB window. deflate64_bound(len) is a conservative output bound. shoco short-string compression: shoco_compress(data) and shoco_decompress(data) use the English model; shoco_compress_with and shoco_decompress_with take a ShocoModel, and shoco_default_model() returns the built-in one. shoco_compress_bound/shoco_decompress_bound give the 2x worst-case bounds. Empty input is CodecTruncated; non-ASCII bytes are escaped with a 0x00 sentinel, and a truncated sentinel or packed code fails closed. BCJ2 is 7z's four-stream x86 CALL/JUMP converter: bcj2_encode(data) -> Result(Bcj2Streams, CodecErr) returns main, call, jump and rc; bcj2_decode(main, call, jump, rc) rebuilds the original bytes, and bcj2_decode_to(..., output_size) checks the declared size. bcj2_encode_with(data, relat_limit, file_size) exposes the conversion limit. The encoder is byte-identical to the LZMA SDK for the tested vectors.
    • xz — xz container compression over liblzma (deps: liblzma): compress(bytes) -> Result(bytes, XzErr) (preset 6, CRC64) and decompress(bytes) -> Result(bytes, XzErr); XzErr is Corrupt, Truncated, TooBig (output over 1 GiB) or Failed.
    • image — PNG decode/encode over libpng (deps: libpng) plus baseline JPEG decode through a vendored JPEG-only stb_image and BNG decode/encode through the Unlicense reference codec; decode(bytes) -> Result(Image{width, height, pixels}, ImgErr) (8-bit RGBA) and encode(Image) -> Result(bytes, ImgErr). decode dispatches BNG, PNG or baseline JPEG by magic; decode_jpeg(bytes) and encode_jpeg(img) are the explicit JPEG entry points, and decode_bng/encode_bng are the BNG entry points. decode_bng_premultiplied/encode_bng_premultiplied preserve the stored premultiplied samples; is_bng(data) tests the signature. ImgErr names which failure: Empty, NotPng, Corrupt on the decode side, BadDims, ShortPixels on the encode side, Failed for an allocation or codec failure. PNG has no 0-dimension image, so an Ok always carries width >= 1.
    • tls — a TLS 1.2/1.3 client over OpenSSL (deps: openssl). Secure by default: connect(host, port) verifies the certificate against the system CA store, checks the hostname, and sends SNI; failure returns a null handle (never a silent insecure connection). connect_timeout(host, port, ms) bounds TCP connect and handshake, and set_timeout_ms(conn, ms) bounds later reads/writes; timeout values outside 0..2,147,483,647 fail closed. write/read/close_conn use the encrypted stream.

    A libc-only shim needs no deps — core:regex, core:os, core:net and core:signal among them; a library with no .pc file can still use extern "Lib" fn for a bare -lLib.

    Testing

    make corelib (→ corelib/run.sh): every corelib/test/<name>/main.ty is built and run, and must produce the golden corelib/test/<name>.out. Re-record goldens with RECORD=1 sh corelib/run.sh. Part of make ci.

    Examples

    Every module also has a small, readable usage example at examples/corelib/<name>/main.ty — idiomatic calls with human-friendly output, as opposed to the assertion-style tests above. make corelib-examples (→ examples/corelib/run.sh) validates them the same way against examples/corelib/<name>.out, with the same dependency skip, and is part of make ci.

    The corelib surface (pre-1.0 — NOT frozen)

    The corelib API is not frozen. The packages above are locked by make corelib and make corelib-examples, which is what makes the surface worth relying on in practice. What follows is the promise:

    • Not frozen. A public function may change name, signature, or semantics before 1.0, with a CHANGELOG.md entry and no deprecation window. In practice changes are additive, but "in practice" is not a contract.
    • Still a regression, not a licence. A bug in a package's documented behavior is a bug to fix, not an excuse to redesign the API around it.
    • Caveats inside the surface stay: core:hash is non-cryptographic and core:md5 is broken for security (use core:sha256), and the FFI-backed packages (core:http, core:tls, core:crypto, core:image, core:sqlite, core:compress) need their external library present at build time (the skip-if-absent convention above).
    • New packages still arrive only through the demand gate — a real program that needs them — and they join the surface the day they ship, with their test + golden + this guide entry.
    • The surface is the same on native Windows (MSYS2/mingw), and so is every signature. Three packages *behave* differently there — core:signal, core:datetime's POSIX-TZ offsets, and core:os's shell-out; each difference is spelled out in SECURITY.md.

    Deprecation path. A package or function is deprecated by (1) a deprecated: notice in its doc comment, (2) an entry in CHANGELOG.md naming the replacement, and (3) a warning: on use emitted by the compiler.

    Step (3) is mechanical: a # deprecated: <text> comment line directly above a fn marks it, and every call site warns with <text>. Deprecated members keep working for the current major version. Removal is a breaking change: it happens only in a major version bump, is recorded in CHANGELOG.md and RELEASE_NOTES.md, and ships with the migration spelled out.

    Before 1.0 none of that binds: a removal needs the changelog entry and nothing else. Which packages are in the frozen surface is a decision 1.0 has to make, not one inherited from this list — see ROADMAP.md.

    Why corelib is shaped this way — the handle guards, the path-check layering, and the shim conventions — is in design-corelib, for maintainers.
